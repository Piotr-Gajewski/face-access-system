# Security policy

This is a research project for a master's thesis: a face recognition access control system built to study presentation and injection attacks. It is not intended for production use.

## Reporting a vulnerability

Please **do not open a public issue**. Report vulnerabilities privately through [GitHub security advisories](https://github.com/Piotr-Gajewski/face-access-system/security/advisories/new). You can expect a reply within a week.

## Scope

In scope: the code in this repository (services, web panel, device software, deployment files).
Out of scope: attacks that are the subject of the research itself (e.g. spoofing the recogniser with photos or screens) – these are expected and measured, but findings are still welcome as regular issues.

## Data

The repository never contains biometric data, recordings, datasets, secrets or model weights with restricted licences. If you find any, please report it as described above.
