# experiments

Definitions and analysis of the study: recognition variants (K, S) combined with defence layers (none, P, P + W), the attacks run against them, and the metrics (APCER, BPCER, FAR, FRR, latency). Each run is tracked in MLflow, so every reported number can be traced to a commit and a run.

Only definitions, analysis code and aggregated results belong here. Datasets, recordings and face images never do.
